# TaskFlow — Task Manager

A responsive task management app for creating, organizing and tracking everyday tasks.

## Features
- Add tasks with a due date, category and priority
- Mark tasks complete or reopen them
- Filter by All, Active and Completed
- Search tasks by title
- Delete individual tasks or clear completed tasks
- Progress summary and task counts
- Saves tasks in the browser with localStorage
- Responsive layout for desktop and mobile

## Run locally
Open `index.html` in a modern browser. No installation or build tools are required.

## Built with
HTML5 · CSS3 · Vanilla JavaScript

## Data note
Tasks are stored in the browser's localStorage on the device and browser where you use the app. They are not synced to an online account.
